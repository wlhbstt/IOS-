# 0.3.0 滑动整理

参考：https://github.com/01MVP/PhotoDelete ，2026-11-13 查阅。

## 范围与设计

- 借鉴按时间/类型/相簿进入、逐张判断、可撤销、批次复核的交互；独立实现，不复制 AGPL 源码、品牌和素材。
- 首页新增“整理”标签，原清理、分类、搜索保留。月份和媒体类型直接来自元数据，不等待 Vision 分析。
- 整理页默认左滑待删、右滑保留、上滑暂存收藏、下滑跳过。手势可自定义，提供对应按钮和撤销。收藏及保护相簿禁止加入待删。
- 滑动仅修改现有待删清单，实际删除继续使用既有 PhotoKit 校验和系统确认。取消系统确认保留清单。撤销恢复动作前的选择状态。
- 在当前整理会话内保留进度；离开并重新开启时从当前集合起点开始，不声称跨重启保存整理历史。待删清单沿用现有内存语义。
- 浏览页增加横向双行/三列网格视图和进入当前筛选结果的逐张整理入口，大小排序、搜索、日期筛选继续有效。
- 删除和收藏分别暂存并复核，收藏只有确认后写入系统相册；撤销恢复动作前的两种待确认状态。
- 入口包含全部、照片、视频、截图、实况、收藏、相簿、月份和地点。地点按照片已有坐标以 0.1° 网格本机分组，显示真实坐标，不宣称城市识别、不请求当前位置、不联网地理编码。
- 压缩普通照片/视频，生成预览后另存新项目。输出不比原资源小时拒绝保存；保留原件。可选删除原件需再次确认，校验原件版本和副本可访问性。
- 大图最多加载当前一张，目标尺寸受限；长列表使用惰性容器。缩略图继续复用已验证的 PhotoKit 请求。

## 步骤与验证

1. 核心会话和月份归组：先写定向测试，验证去留、撤销、边界、日期和媒体筛选。
2. SwiftUI 首页、相簿、滑动页与浏览入口：本地语法/项目检查；云端 Xcode 编译与原生 UI 流程。
3. 原生测试涵盖实际照片加载、左右滑、按钮、撤销、取消删除、系统确认、删除后计数；检查截图后交付 IPA。

## 边界

- 按用户追加清单包含本机压缩、位置分组和自定义手势；不增加付费、账户或成就。
- 图片转换为静态 JPEG，视频转换为普通 MP4；必须接受有损转换。实况、RAW、动画、连拍与多资源编辑内容保守拒绝。
- Windows 不提供 Apple SDK；本地核心测试不替代云端构建或 iPhone 真机性能验收。
- iOS 后台调度和已有分析实现保持原有行为；本次不承诺后台持续运行。
