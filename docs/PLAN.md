## 边界

- 不上传照片或 OCR 内容；云端构建不包含 Apple 账号密码。
- 不使用私有 `fileSize` KVC；iOS 18.5 的精确大小通过公开接口读取资源后累计字节数。
- 原始媒体文件大小不等于手机实际占用或立即回收空间。
- 截图和模糊识别仅提供候选；所有删除均由用户确认，并保留系统确认。
- 不改动 `gps-file` 或其他既有 Java 项目，不自动创建公开仓库或上传私人数据。
