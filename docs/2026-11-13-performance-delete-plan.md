# 删除与万张图库响应优化

用户反馈：照片删不掉、分析慢、内存大、搜索不准，要求直接删除到系统最近删除。

## 方案

- 删除只核验所选照片及重复组保留项的当前元数据、收藏和保护相簿，调用 PhotoKit 系统确认。不等待扫描结束或全库相似匹配，不永久清空最近删除。
- 快速分析使用缩略图，原件大小和 SHA256 单独按需扫描。分批保存和发布进度，相似匹配在后台完成，取消后不能重新写回旧照片。
- 缩略图按显示尺寸请求并在离屏时释放；Vision 同步工作使用 autoreleasepool；界面快照不携带特征数据。
- 搜索补充中文类别别名、全角归一化、OCR 换行和中文日期，保留多关键词 AND 语义，取消过期任务。
- 根据追加要求使用 ui-ux-pro-max 的 SwiftUI 指南改进首页、真实照片预览、选择状态和删除操作栏；保持原生系统字体、深浅色和 44pt 触控区域。云端用隔离模拟器与公开样片保存界面截图，不读取用户照片。
