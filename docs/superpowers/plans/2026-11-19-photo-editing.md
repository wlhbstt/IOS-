# 照片编辑实现计划

**目标：** 从照片详情编辑单张普通照片或 Live Photo，预览后选择保存到原图或另存。首版包含本机 AI 美化、静态主体抠图和虚化。

**架构：** 编辑参数放在核心包以便在 Windows 的 Swift 环境验证。编辑器只加载当前照片。Core Image 和 MetalPetal 负责渲染，Vision 负责本机识别，PhotoKit 负责预览和保存。

- [ ] 验证编辑参数的强度边界、裁剪比例和旋转方向。先运行新增核心测试，确认缺少实现时失败。
- [ ] 连接裁剪和调色工具、按住对比、撤销和重置。用 iOS 模拟器流程验证从详情进入与渲染结果。
- [ ] 验证保存到原图与另存副本的相册项变化。实况单独核对成对资源、声音和可还原性。
- [ ] 运行现有完整回归并校验 Release IPA。单独记录真机验收范围。
